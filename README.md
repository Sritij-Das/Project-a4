# 🌡️ Temperature_Converter

## 📌 Project Description
Temperature Converter is a simple Python-based project that allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin** scales.

The program uses a menu-driven approach and a `while` loop to allow users to perform multiple conversions without restarting the program. It also provides an option to display all temperature conversion formulas whenever required.

## ✨ Features
- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- Convert Celsius to Kelvin.
- Convert Kelvin to Celsius.
- Convert Fahrenheit to Kelvin.
- Convert Kelvin to Fahrenheit.
- Display all six temperature conversion formulas.
- Perform multiple conversions using a `while` loop.
- Exit the program whenever required.
- Handle invalid menu choices.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Concepts Used:**
  - While Loop
  - If-elif-else Statements
  - Break and Continue Statements
  - User Input and Output
  - Arithmetic Operations

## 📐 Temperature Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius to Fahrenheit | (C × 9/5) + 32 |
| Fahrenheit to Celsius | (F − 32) × 5/9 |
| Celsius to Kelvin | C + 273.15 |
| Kelvin to Celsius | K − 273.15 |
| Fahrenheit to Kelvin | (F − 32) × 5/9 + 273.15 |
| Kelvin to Fahrenheit | (K − 273.15) × 9/5 + 32 |

## 🚀 How to Run the Project

**Step 1:** Clone the repository.
```bash
git clone https://github.com/Sritij-Das/Temperature_Converter.git
```

**Step 2:** Navigate to the project directory.
```bash
cd Temperature_Converter
```

**Step 3:** Run the Python program.
```bash
python temperature_converter.py
```
